# 변수 정의 메모

결정 주체(유저/운영자/시스템)와 성격(상품 속성/일 단위 흐름/상태)을 기준으로 정리.

## 시스템 계산 변수 (수식 기반)

- 자산 (assets)
  - 정의: 자본 + 부채
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 회계등식 기반. 재무 상태의 총량을 나타냄.

- 매출 (revenue)
  - 정의: 객단가 * 주문건
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 일 단위 매출 계산식.

- 객단가 (avg_order_price)
  - 정의: 정가 * 합포장 * (1-할인율)
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 할인 및 합포장 반영 단가.

- 주문건 (orders)
  - 정의: min(고객수 * 전환율, 재고량)
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 수요와 재고를 동시에 반영한 주문 수.

- 고객수 (customers)
  - 정의: 신규고객 + 기존고객
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 일 단위 총 고객 수.

- 신규고객 (new_customers)
  - 정의: 마케팅비 / 고객획득효율
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 마케팅 효율에 따른 유입 고객 수.

- 기존고객 (existing_customers)
  - 정의: 기존고객(D+1) = 기존고객 * (1-이탈율)
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 자연 감소 압박을 위한 고객 유지율 반영.

- 이탈율 (churn_rate)
  - 정의: 기본이탈율 / (100 + 브랜딩)
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 브랜딩 지표를 높이면 이탈율이 자연 감소.

- 전환율 (conversion_rate)
  - 정의: 기준전환율 * 산업지수 * 상품지수 * 경쟁지수
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 시장/상품/경쟁 영향 반영.

- 매출실적 (total_revenue)
  - 정의: 매출실적(D+1) = 매출실적 + 매출
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 누적 매출 집계.

- 현금흐름 (cash_flow)
  - 정의: 현금흐름(D+1) = 현금흐름 + 대출 + 매출 - 비용 - 매입
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 일 단위 현금 변동.

- 매입 (purchase_cost)
  - 정의: 매입수량 * 원가
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 생산/구매에 따른 원가 지출.

- 비용 (expenses)
  - 정의: 변동비 + 고정비
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 운영 전체 비용 합계.

- 변동비 (variable_cost)
  - 정의: 수수료 + 물류비 + 마케팅비 + 원가비
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 매출/생산 규모에 따라 변동.

- 수수료 (fees)
  - 정의: 매출 * 수수료율
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 거래/플랫폼 수수료.

- 물류비 (logistics_cost)
  - 정의: (기본물류비 + 변동물류비) * 주문건
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 주문당 물류 비용 합계.

- 변동물류비 (variable_logistics_cost)
  - 정의: 무게 * 단위물류비
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 무게 기반 변동 물류비.

- 원가비 (cost_of_goods_sold)
  - 정의: 주문건 * 상품원가
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 매입 시점이 아니라 판매 시점에 비용으로 인식.

- 고정비 (fixed_cost)
  - 정의: 인건비 + 임대료 + 이자비
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 매출과 무관한 고정 운영비.

- 인건비 (labor_cost)
  - 정의: 직원연봉의 합계 / 365
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 일 단위 인건비.

- 임대료 (rent)
  - 정의: 연간 임대료 / 365
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 일 단위 임대료.

- 이자비 (interest_cost)
  - 정의: 대출 * 이자율 / 365
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 일 단위 이자 비용.

- 고객획득비용 (customer_acquisition_cost)
  - 정의: 고객획득비용 = 기본고객획득비용 * 100 / (100 + 마케팅효율)
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 마케팅 효율이 높을수록 CAC가 감소.

- 재고량 (inventory)
  - 정의: 재고량(D+1) = 재고량 - 주문건 * 합포장 + 매입수량
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 주문 출고와 매입 입고를 반영한 일 단위 재고 변화.

## 유저 결정 변수

- 유저 결정 항목
  - 정의: 유저가 구매를 선택할 수 있는 게임 내 결정
  - 구성: 사무실임대, 인력충원, 상품매입, 기술개발, 프로모션
  - 메모: 각 결정은 비용/효율/상태 변수에 영향을 줄 수 있음.

- 매입수량 (purchase_quantity)
  - 정의: 이용자의 매입 의사결정으로 설정되는 구매 수량 (MOQ 기반)
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: MOQ(최소주문수량) 제약을 반영한 매입 결정값으로 재고 증가 계산에 사용.

- 마케팅효율 (marketing_efficiency)
  - 정의: 고객획득비용 감소에 영향을 주는 효율 지표
  - 타입: 수치 (float)
  - 초기값: 추후 확정
  - 메모: 유저 선택 변수이며 직원 구매 등으로 향상 가능.

## 운영자 설정 변수

- 기본이탈율 (base_churn_rate)
  - 정의: 이탈율의 기준값
  - 타입: 수치 (float)
  - 초기값: 5%
  - 메모: 운영자가 난이도 조정 가능.

- 기준전환율 (base_conversion_rate)
  - 정의: 전환율의 기준값
  - 타입: 수치 (float)
  - 초기값: 3%
  - 메모: 운영자가 난이도 조정 가능.

- 산업지수 (industry_index)
  - 정의: 산업 환경을 반영하는 지수
  - 타입: 수치 (float)
  - 초기값: 1
  - 메모: 운영자 정의.

- 상품지수 (product_index)
  - 정의: 상품 경쟁력을 반영하는 지수
  - 타입: 수치 (float)
  - 초기값: 1
  - 메모: 운영자 정의.

- 경쟁지수 (competition_index)
  - 정의: 경쟁 강도를 반영하는 지수
  - 타입: 수치 (float)
  - 초기값: 1
  - 메모: 운영자 정의.

- 기본고객획득비용 (base_customer_acquisition_cost)
  - 정의: 고객획득비용의 기준값
  - 타입: 수치 (float)
  - 초기값: 20000
  - 메모: 기준 CAC.

- 기본물류비 (base_logistics_cost)
  - 정의: 주문 1건당 고정 물류비
  - 타입: 수치 (float)
  - 초기값: 3000
  - 메모: 주문당 기본 비용.

- 단위물류비 (logistics_cost_per_weight)
  - 정의: 무게 1단위당 물류비
  - 타입: 수치 (float)
  - 초기값: 100
  - 메모: 변동물류비 계산에 사용.

- 이자율 (interest_rate)
  - 정의: 대출에 적용되는 기본 이자율
  - 타입: 수치 (float)
  - 초기값: 5%
  - 메모: 기본이자율.

## 상품 속성 (상품별 상이)

- 상품 (product)
  - 정의: 판매/재고/매입 계산의 기준 단위인 상품 엔터티
  - 타입: 객체 (예: 이름, 가격, 원가 등 속성 포함)
  - 초기값: 추후 확정
  - 메모: 향후 구매/상품관리 기능의 기본 단위.

- 정가 (list_price)
  - 정의: 상품의 기준 판매가
  - 타입: 수치 (float)
  - 초기값: 상품별 상이
  - 메모: 할인 전 가격.

- 할인율 (discount_rate)
  - 정의: 정가에 적용되는 할인 비율
  - 타입: 수치 (float)
  - 초기값: 상품별 상이
  - 메모: 0~1 또는 0~100 스케일은 구현 시 확정.

- 합포장 (bundle_size)
  - 정의: 주문 1건당 출고되는 상품 수량
  - 타입: 수치 (float)
  - 초기값: 1
  - 메모: 합포장 = 1 + 할인율 * 2

- 상품원가 (product_cost)
  - 정의: 상품 1개 기준 원가
  - 타입: 수치 (float)
  - 초기값: 상품별 상이
  - 메모: 원가비 계산에 사용.

- 무게 (weight)
  - 정의: 상품 1개 기준 무게
  - 타입: 수치 (float)
  - 초기값: 상품별 상이
  - 메모: 물류비 계산에 사용.

- MOQ (minimum_order_quantity)
  - 정의: 특정 제품을 구매할 수 있는 최소수량
  - 타입: 수치 (float)
  - 초기값: 상품별 상이
  - 메모: 매입 의사결정 시 하한 제약으로 사용.
